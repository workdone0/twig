Documentation

Twig, end to end.

A single-binary terminal UI for exploring JSON and YAML. This guide covers installation, the keymap, every CLI flag, and the things that go wrong.

Introduction

Twig is a high-performance, terminal-based data explorer for JSON and YAML. It bridges the gap between simple text viewers (like less) and full-blown IDEs.

Designed for developers who work with large datasets, Kubernetes manifests, log exports, and complex configuration files, Twig parses data into a navigable tree structure and lets you search, jump, and inspect without ever leaving the terminal.

Since v3.0.0, Twig is a single ~4 MB static binary written in Rust. Drop it on any Linux, macOS, or Windows machine and it runs — no Python, no runtime.

Installation

The recommended way to install Twig is the one-line installer — it downloads the matching prebuilt binary from the latest GitHub release, verifies its SHA-256 checksum against the published *.sha256 file, and installs it to ~/.local/bin (or /usr/local/bin when writable).

One-line installer

curl -fsSL https://twig.wtf/install.sh | sh

Useful flags

# Pin a specific release
curl -fsSL https://twig.wtf/install.sh | sh -s -- --version v3.0.0

# Install to a custom directory
curl -fsSL https://twig.wtf/install.sh | sh -s -- --to /usr/local/bin

# Build from source instead of downloading
curl -fsSL https://twig.wtf/install.sh | sh -s -- --method build

# Skip the install confirmation prompt
curl -fsSL https://twig.wtf/install.sh | sh -s -- --yes

Run curl -fsSL https://twig.wtf/install.sh | sh -s -- --help for the full flag list.

Cargo

cargo install twig

cargo-binstall

cargo binstall twig

Manual download

Prebuilt .tar.gz archives with matching *.sha256 checksum files are on the Releases page.

  • Linux: x86_64-unknown-linux-gnu, aarch64-unknown-linux-gnu
  • macOS: x86_64-apple-darwin (Intel), aarch64-apple-darwin (Apple Silicon)
  • Windows: x86_64-pc-windows-msvc

Build from source

Requires Rust 1.75 or later.

git clone https://github.com/workdone0/twig.git
cd twig
cargo build --release
./target/release/twig --help

Quickstart

Open a file

Pass a JSON or YAML file as the argument. Format is auto-detected from the extension. 

twig data.json     # or twig config.yaml

Repair malformed JSON

--fix attempts to repair common malformations — trailing commas, unquoted keys, single quotes, NaN/Infinity — and writes a clean, round-trippable copy. 

twig --fix bad.json -o clean.json

Pretty-print to stdout

Non-TUI mode that emits a colored, indented copy of the file. 

twig -p large.json > pretty.json

Benchmark streaming ingestion

--check loads the file through the same streaming pipeline the TUI uses and prints size, node count, elapsed time, and throughput. Non-TUI. Useful in CI and ad-hoc perf checks. 

twig --check huge.json

CLI reference

twig [OPTIONS] <FILE>

Arguments

  • <FILE> — path to a JSON or YAML file

Options

  • -p, --print — print pretty-printed output to stdout (non-TUI)
  • -o, --output <FILE> — write to FILE instead of stdout (with --print or --fix)
  • -i, --indent <N> — indent width for pretty-printed or fixed output (default: 2)
  • --fix — attempt to repair malformed JSON and write a clean copy
  • --check — load and print size, node count, elapsed, throughput (non-TUI)
  • --rebuild-db — drop the on-disk SQLite cache before loading
  • --version — print version and exit
  • --help — print help and exit

Configuration

Twig is zero-config by default. It persists your settings between sessions.

  • Theme — Catppuccin Mocha (default) and Solarized Dark ship in the box. Cycle with t. Your choice is saved and restored on the next launch.
  • Config file — stored at ~/.config/twig/config.json (or the platform equivalent). Shared with the legacy Python implementation, so theme preference carries over when upgrading from twg.
  • Cache — a SQLite file with an FTS5 virtual table, stored under the platform's cache directory. Safe to delete at any time; rebuilt on the next launch.

Troubleshooting

Loader errors

If Twig can't parse a file, it shows the error in-app (press any key to exit) and prints a colored message with a --fix hint to stderr with exit code 1. Shell pipelines see the failure immediately without having to inspect TUI screenshots.

"Database is locked" error

If Twig crashes or is killed forcefully, the SQLite lock might remain. Run with --rebuild-db to reset.

Clipboard not working

On Linux headless servers without a clipboard daemon, the copy actions (c, y) fall back to writing the payload to a temporary file and printing its path. The TUI shows a hint when this fallback fires.

Cross-compile issues when building from source

The Cargo.toml in the repo points the aarch64-unknown-linux-gnu linker at aarch64-linux-gnu-gcc. To cross-compile locally on Debian/Ubuntu, install the cross tools: 

sudo apt-get install -y gcc-aarch64-linux-gnu libc6-dev-arm64-cross

The CI uses cargo-cross, which pulls a Docker image with the right toolchain preinstalled.
