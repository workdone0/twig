Documentation

Twig is a high-performance, terminal-based data explorer for JSON and YAML. Since v3.0.0 it's a single ~4 MB static binary written in Rust — drop it on any Linux, macOS, or Windows machine and it runs. No Python, no runtime.

Designed for developers who work with large datasets, Kubernetes manifests, logs, or complex configuration files, Twig parses data into a navigable tree structure, allowing for rapid inspection without ever leaving the terminal.

Installation

The recommended way to install Twig is the one-line installer — it downloads the matching prebuilt binary from the latest GitHub release, verifies its SHA-256 checksum, and installs it to ~/.local/bin (or /usr/local/bin when writable).

One-line installer (recommended)

curl -fsSL https://twig.wtf/install.sh | sh

Useful flags

# Pin a specific release
curl -fsSL https://twig.wtf/install.sh | sh -s -- --version v3.0.0

# Install to a custom directory
curl -fsSL https://twig.wtf/install.sh | sh -s -- --to /usr/local/bin

# Build from source instead of downloading
curl -fsSL https://twig.wtf/install.sh | sh -s -- --method build

# Skip the confirmation prompt
curl -fsSL https://twig.wtf/install.sh | sh -s -- --yes

Other methods

Cargo

cargo install twig

cargo-binstall

cargo binstall twig

Manual download

Prebuilt .tar.gz archives with matching *.sha256 checksum files are available on the Releases page for Linux (x86_64, aarch64), macOS (Intel, Apple Silicon), and Windows (x86_64).

Build from source

Requires Rust 1.75 or later.

git clone https://github.com/workdone0/twig.git
cd twig
cargo build --release
./target/release/twig --help

Legacy Python version (≤ v2.1.4)

Older releases shipped to PyPI as twg. That implementation is preserved on the legacy-python branch for reference. New development happens on master.

Core Workflow

Pass a data file to Twig. It automatically detects the format (JSON or YAML), indexes it via streaming ingestion, and launches the TUI. 

twig data.json     # or twig config.yaml

Repair malformed JSON

Automatically repair common errors (trailing commas, unquoted keys, single quotes, NaN / Infinity) and write a clean round-trippable copy. 

twig --fix bad.json -o clean.json

Benchmark streaming ingestion

Non-interactive mode that exercises the same streaming pipeline the TUI uses and prints size, node count, elapsed time, and throughput. Useful in CI and ad-hoc perf checks. 

twig --check huge.json

CLI Reference

twig [OPTIONS] <FILE>

--fix

Attempt to repair malformed JSON and write a clean copy.

twig --fix broken.json -o clean.json

--print / -p

Pretty-print the file to stdout with syntax highlighting.

twig -p large.json

--check

Load the file and print size, node count, and throughput stats. Non-TUI.

twig --check huge.json

--output / -o

Write to a file instead of stdout (with --print or --fix).

--indent / -i

Indent width for pretty-printed or fixed output. Default: 2.

--rebuild-db

Drop the on-disk SQLite cache before loading.

--version

Print version and exit.

Configuration

Twig is zero-config by default. It automatically persists your settings between sessions.

  • Theme: Catppuccin Mocha (default) and Solarized Dark ship in the box. Cycles themes with the t key.
  • Config: stored at ~/.config/twig/config.json (or the platform equivalent). Shared with the legacy Python implementation, so theme preference carries over when upgrading.
  • Cache: a SQLite file with an FTS5 virtual table, stored under the platform's cache directory. Safe to delete at any time.

Troubleshooting

Loader errors

If Twig can't parse a file, it shows the error in-app (press any key to exit) and prints a colored message with a --fix hint to stderr with exit code 1, so CI pipelines fail fast.

"Database is locked" error

If Twig crashes or is killed forcefully, the SQLite lock might remain. Run with --rebuild-db to reset.

Clipboard not working

On Linux headless servers without a clipboard daemon, the copy actions (c, y) fall back to writing the payload to a temporary file and printing its path. The TUI shows a hint when this fallback fires.
