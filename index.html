Quickstart

Up and running in three commands.

Install Twig, open a file, and you're navigating with the keyboard in under a minute.

  1. 01

    Step 1

    Install the binary

    Downloads the prebuilt release for your platform, verifies its SHA-256, and drops twig into your path. 

    curl -fsSL https://twig.wtf/install.sh | sh
  2. 02

    Step 2

    Open a file

    Format auto-detected from the extension. No flags, no config — just point Twig at a file. 

    twig data.json
  3. 03

    Step 3

    Navigate with the keyboard

    The mouse never has to leave the desk. Everything Twig does is a keystroke away. 

    ↑ ↓ ← →    move
/          search
:          jump to path
c          copy path
q          quit

Why Twig

Built for the terminal.

A focused tool for a specific job. Twig does one thing — interactive JSON and YAML exploration — and does it without making you learn a new DSL, paste production data into a browser, or install a heavy IDE plugin.

Versus

jq

jq is the right tool for transforming JSON. Twig is the right tool for exploring it — no syntax to learn, no expressions to write, no pipeline to design. Just point and look.

Versus

Web viewers

Pasting production data — API responses, K8s manifests, log exports — into a browser is a security risk. Twig runs entirely on your machine. Works over SSH, on air-gapped boxes, on shared servers.

Versus

IDE plugins

IDE JSON tools are heavy and GUI-only. Twig is a single ~4 MB binary that runs anywhere a terminal does — including inside your editor's integrated terminal, over SSH, on a fresh container.
