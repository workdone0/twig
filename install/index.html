INSTALL TWIG

Install once.
Open any time.

Choose your platform. Each installer downloads a release, verifies its checksum and version, and installs the terminal app for your account.

No Rust or Python needed for a prebuilt release.

Full installation guide ↗
BASH / ZSH
curl -fsSL https://twig.wtf/install.sh | bash

For macOS and Linux with GNU libc. Installs to ~/.local/bin. Requires Bash, curl, and tar.

  1. Run the command in your terminal.
  2. Add ~/.local/bin to PATH if the installer asks.
  3. Run twig --version to check the installation.

KEEP

Choose what stays on disk.

The terminal app stores parsed data in an unencrypted local cache. Use --no-cache for temporary disk storage, or --clear-cache to remove saved caches.

Understand local storage ↗
COPY

Copy the value you need.

Copy a path with c or the selected value with y. Copy exports the complete selection up to 10,000 nodes; the inspector remains a limited preview.

01

Format JSON with readable indentation

twig --print response.json --indent 4
02

Repair JSON into a separate file

twig --fix broken.json -o repaired.json
03

Check a file without keeping a cache

twig --check --no-cache data.json
